#  Temperature Converter Web Application

A simple and user-friendly **Temperature Converter** built using **HTML, CSS, and JavaScript**.  
This application converts temperature values between **Celsius, Fahrenheit, and Kelvin**.

## Project Description

The Temperature Converter allows users to:
- Enter a temperature value
- Select the source unit (Celsius / Fahrenheit / Kelvin)
- Select the target unit
- Convert the temperature with a single click
- View the converted result instantly

The project focuses on clean UI design, proper input validation, and accurate conversion logic.

## Features

- Convert between Celsius (°C), Fahrenheit (°F), and Kelvin (K)
- Input validation for numeric values
- User-friendly and responsive interface
- Output displayed in a textbox
- Clean code structure with separate HTML and CSS files

## Technologies Used

- **HTML** – Structure of the web page  
- **CSS** – Styling and layout  
- **JavaScript** – Temperature conversion logic and validation

## How to Run the Project

1. Download or clone the repository  
2. Open `index.html` in any modern web browser  
3. Enter a temperature value  
4. Select **From** and **To** units  
5. Click on **Convert** to see the result
